# 沈知微 1.0：在后台和你说话

沈知微的首个开源源码版本。

## 这版做了什么

- 莫比乌斯环成为主界面的中心；回复以短字幕显示，长回答可以展开。
- 主页面移除语音线路选择按钮，统一在设置中调整。
- 我的项目、执行动态和 Agent 工作台支持独立收放，并记住本机选择。
- 增加专注视图，利用收起面板后的空间放大主环。
- 增加 Windows 后台 Ctrl＋空格按住说话入口；右下角小环不抢焦点、不拦截鼠标，结束后收起。
- 后台音频组件预热期间不采集音频，按键后才打开麦克风。
- 支持按需附带当前窗口画面；不支持图片的模型使用窗口文字，并明确提示能力。
- 保留各 Agent 的独立项目、真实连接阶段计时和 Codex 写锁冲突处理。

## 使用前

这是源码包，需要自行安装 Node.js、运行依赖以及所需 Agent，并配置自己的账号与语音服务。源码包不包含个人运行数据、登录信息、录音、声纹或密钥。

后台功能目前面向 Windows。读屏默认关闭，可在设置中主动开启。后台朗读使用百炼龙婉，会产生相应服务用量。

## 验收边界

离线测试和本机设备检查已通过，具体实测及待本人体验项目见《验收记录》。真实语音听感、回声环境以及每个外部 Agent 的实际文档任务，需要在自己的环境中验证。
