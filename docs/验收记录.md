- 完整离线回归：468 项测试，其中 467 项通过、1 项按 Windows 平台条件跳过，失败为 0。运行使用明确的离线文件清单。

- 已回归后台语音与主界面语音的互斥、快速松开、停止、Agent 选择绑定、图片与文字上下文、草稿及会话写锁行为。
- 真实服务实测脚本已增加自动发现保护；默认离线测试不会启动真实模型、语音服务或桌面任务。
