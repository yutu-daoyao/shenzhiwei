# 隐私说明

沈知微是本机运行的调度客户端，模型和语音服务由你自行配置。

## 本机数据

项目登记、会话索引、运行日志、设置和可选的声纹特征保存在本机运行数据目录。开发目录中的 `data/`、录音、数据库、密钥文件和本机原生缓存均被排除在 Git 和源码发行包之外。

声纹必须由本人明确勾选同意后录入；声纹特征只在本机加密保存，可通过设置删除。录入用的音频不包含在源码发行版中。

音频组件预热只编译本项目的本机音频代码，不打开麦克风。后台按住说话时开始采集，松开后关闭采集；关闭后台语音会取消未完成的识别和播放。没有按键授权时，后台入口不持续录音。

## 发送给服务的数据

识别音频会按你选择的方式发送到语音识别服务；朗读文字会发送到合成服务。所选 Agent 会将任务文字及按需附带的上下文发送到它配置的模型服务。

开启读屏设置后，本次按键语音可以附带按键时所在窗口的画面。知微不单独保存截图文件，但画面和文字可能进入所选 Agent 的会话历史。请不要在不希望发送给模型的窗口上使用开启读屏的语音入口。

读屏会检查前台窗口身份；密码控件、安全桌面、窗口变化或无法核实的画面会拒绝读取。任何自动检查都不应被理解成能识别所有敏感内容。你可以关闭读屏，只发送语音识别文字。

## 登录与实验接入

Codex 登录类型通过官方接口查询。其他执行器沿用各自登录。知微不会将账号登录文件打进发布包。

网易识别是可选的实验能力，只有在设置中明确同意后才读取对应客户端的专用登录会话。读取到的会话仅用于向对应网易服务认证，不写入项目日志；过期后需要本人处理登录。

## 停止与删除

从托盘退出知微会关闭本机后台和属于知微的音频、托盘进程。关闭主界面本身不退出后台。

删除本机运行数据之前，请先退出知微，并备份需要保留的项目登记和记录。删除知微的本机数据不会替你删除第三方 Agent 或服务商已经保存的记录。
