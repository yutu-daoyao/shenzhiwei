# 沈知微

一个以语音为入口的 Windows 个人助理。你选择 Agent、模型和项目，知微负责把任务交给对应执行器，并呈现真实进度。

![沈知微的专注视图](docs/界面预览.png)

## 像和身边的助手说话

- **主界面以莫比乌斯环为中心。** 说话与工作时保持呼吸感，回复以简短字幕显示在环下方，长回答可展开。
- **面板按需展开。** 我的项目、执行动态和上方工作台都能单独收起，也可以一键进入专注视图。选择会保存在本机浏览器中。
- **后台按住说话。** 按住 **Ctrl＋空格**，等小环提示正在听后说话，松开后发送。知微不会切到前台；右下角的小环和字幕不抢键盘焦点，也不拦截鼠标。回答结束后自动收起。
- **结合当前窗口。** 开启设置中的读屏选项后，本次语音可以附带当前窗口画面。模型不支持图片时使用可读取的窗口文字，并明确提示；无法读取时不会假装看到了屏幕。
- **保持执行器各自的工作空间。** 支持 Codex、OpenCode、WorkBuddy、DeepSeek Harness 等已经接入的本机执行器；知微自身工程交给 Codex 维护，其他执行器操作各自选定的项目。

这是一份源码发行版，需要自行安装运行环境和需要使用的 Agent。它不附带模型账号、语音密钥、个人项目、聊天历史、录音或声纹。

## 开始使用

环境：Windows、Node.js 22.13 或更新版本。本机开发和验证使用 Node.js 24。后台全局按键、小环和本机音频适配目前仅支持 Windows；其他系统可以使用支持范围内的文字功能。

```powershell
git clone https://github.com/yutu-daoyao/shenzhiwei.git
cd shenzhiwei
npm ci --ignore-scripts
npm start
```

在浏览器打开本机地址 **http://127.0.0.1:4317**。

双击 `open-zhiwei.vbs` 也可以启动独立界面。关闭界面后，后台和托盘继续运行；从托盘选择「退出知微」才会退出后台。不默认添加开机启动。

## 配置 Agent 与语音

在工作台选择已经安装并完成官方登录的 Agent、项目目录和模型。各执行器沿用自己的登录与模型配置。知微不会替你购买额度，也不会自动改用另一个付费模型。

Codex 使用官方 ChatGPT 登录。还没登录时，请先在官方终端执行 `codex login`。其他执行器同样先在自己的官方客户端中完成登录。

语音线路统一放在右上角「设置与检查」中。后台按键语音使用这里配置的识别服务与龙婉朗读；需要百炼服务时，在启动知微的终端配置自己的密钥：

```powershell
$env:DASHSCOPE_API_KEY = "替换为你自己的百炼密钥"
npm start
```

不要将真实密钥写入源码或提交到 Git。语音服务产生的费用以对应服务商账单为准。网易识别属于实验接入，不作为默认方式；登录失效时需要本人重新登录，知微不会自动切换付费服务。

## 后台使用

1. 在设置中启用「后台快捷键」。页面会显示 Ctrl＋空格是否注册成功。
2. 保持 Word、浏览器或其他工作窗口在前台，按住 Ctrl＋空格。
3. 小环提示正在听后说话，松开发送。首次启动会预编译音频组件，预编译不会打开麦克风。
4. 再次按住快捷键可以打断知微的朗读并继续说话；说「知微，停一下」可以请求停止当前任务。工具是否真正停止，以执行器的确认状态为准。
5. 如需审批，从托盘打开知微查看。小环只提醒，不自动替你批准写入、命令或外部操作。

快捷键已被其他程序占用时，设置会明确提示，不会夺取另一个程序的快捷键。

## 会话与状态

连接过程分别显示启动、登录检查、模型读取和恢复会话的真实耗时。协议没有独立登录检查接口时会明确标注。每个执行器的计时写在自己的本机 `agent-connection.jsonl` 中。

知微确认持有 Codex 会话的写入权后才写入，空闲时主动退订。遇到其他客户端占用时保留原对话，并提供「稍后重试」和「新建对话继续」。接口未返回占用客户端名称时，不会猜测客户端身份。

## 数据与边界

- 服务只监听本机回环地址；不要直接暴露到公网。
- 后台麦克风由按键主动触发，松开后关闭采集；模型处理与朗读可以继续。
- 知微不单独落盘保存读屏截图。附带的画面和文字会发送到所选 Agent，可能进入该 Agent 的会话记录，并按它的配置发送到模型服务。
- 切换窗口、锁屏或发现密码控件时，读屏可能拒绝执行。画面读取失败会明确提示；不根据猜测操作。
- 录音、声纹、密钥、会话索引和运行日志不属于源码发行包。详见[隐私说明](docs/隐私说明.md)。

## 验证与贡献

```powershell
npm test
```

自动测试包含模拟协议、临时文件和页面交互，不使用你的模型额度。真实服务、真实麦克风与实际桌面体验需要分别验收，不能仅凭自动测试推断。

问题反馈请附操作步骤、界面状态和脱敏后的错误；不要上传密钥、登录会话、私人文档或录音。参见[贡献说明](CONTRIBUTING.md)。

本项目参考了 [T3 Code](https://github.com/pingdotgg/t3code) 的连接阶段与会话管理思路，相关改动为独立实现。界面中的环形美术资产在项目开发过程中生成。
